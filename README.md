# Лёд на Марсе. Распределение CO₂ и H₂O льда

## Цель проекта
Визуализировать пространственное распределение углекислого (CO₂) и водяного (H₂O) льда на поверхности Марса на основе данных, полученных с инфракрасного спектрометра SPICAM-IR, установленного на борту орбитального аппарата Mars Express.

## Описание переменных:
- `lat`, `lon` — географические координаты (широта и долгота) точки наблюдения на Марсе  
- `co2ice_index` — индекс наличия CO₂-льда (значения > 2 считаются детекцией льда)  
- `h2oice_index` — индекс наличия H₂O-льда (значения > 0.15 считаются детекцией льда)  
- `ls` — солнечная долгота (сезон на Марсе, от 0° до 360°)  
- `martian_year` — марсианский год  
- `snr` — отношение сигнала к шуму
